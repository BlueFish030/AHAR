# Attribution

AHAR (AlvaAR fork) is derived from and builds upon the following open-source projects.

## Core SLAM

- **[AlvaAR](https://github.com/alanross/AlvaAR)** by Alan Ross — original browser WASM SLAM (GPLv3)
- **[OV²SLAM](https://github.com/ov2slam/ov2slam)** — visual SLAM foundation (GPLv3)
- **[ORB-SLAM2](https://github.com/raulmur/ORB_SLAM2)** — SLAM algorithms and concepts (GPLv3)

## Dependencies (vendored in `src/libs/`)

- **[OpenCV](https://opencv.org/)** — computer vision (Apache 2.0)
- **[Eigen](https://eigen.tuxfamily.org/)** — linear algebra (MPL2)
- **[Ceres Solver](https://github.com/ceres-solver/ceres-solver)** — optimization (BSD)
- **[Sophus](https://github.com/strasdat/Sophus)** — Lie group math (MIT)
- **[OpenGV](https://github.com/laurentkneip/opengv)** — multi-view geometry (BSD)
- **[iBoW-LCD](https://github.com/emiliofidalgo/ibow-lcd)** / **[OBIndex2](https://github.com/emiliofidalgo/obindex2)** — loop closure (GPLv3)
